# Multi-Disease Prediction System Using Machine Learning

The Multi-Disease Prediction System is a machine learning-based healthcare application designed to predict the likelihood of various diseases using patient medical data. The primary objective of this project is to assist in the early detection of diseases by analyzing relevant health parameters and generating predictions based on trained machine learning models. The system currently focuses on three major diseases: Heart Disease, Diabetes, and Breast Cancer.

The project utilizes publicly available medical datasets to train and evaluate predictive models. For Heart Disease prediction, attributes such as age, sex, chest pain type, cholesterol level, blood pressure, and other cardiovascular indicators are used. Diabetes prediction is based on factors including glucose level, blood pressure, insulin level, body mass index (BMI), age, and diabetes pedigree function. Breast Cancer prediction uses diagnostic measurements extracted from breast mass examinations. These datasets are preprocessed, cleaned, and divided into training and testing sets to ensure accurate model development.

Multiple machine learning algorithms were implemented and compared, including Logistic Regression, Support Vector Machine (SVM), Random Forest, and XGBoost. Each algorithm was trained and evaluated using performance metrics such as accuracy. The best-performing model for each disease was selected and saved for deployment. This comparative analysis helped identify the most suitable algorithm for each prediction task and improved the overall reliability of the system.

The user interface of the application was developed using Streamlit, providing an interactive and user-friendly platform. Users can select the disease they wish to predict, enter the required medical parameters, and receive instant predictions. The trained models are loaded using Joblib, enabling efficient and fast predictions without retraining the models every time the application is executed.

This project demonstrates the practical application of machine learning in the healthcare domain by combining data preprocessing, model training, evaluation, and deployment into a single integrated system. The solution can assist healthcare professionals and individuals by providing preliminary disease risk assessments. Future enhancements may include support for additional diseases, integration with real-time health monitoring devices, improved visualization dashboards, explainable AI techniques, and cloud deployment for wider accessibility.
